# META-USAGE

Файл фіксує суттєве використання систем штучного інтелекту під час роботи. Записуємо одразу, а не наприкінці семестру. Не потрібно фіксувати кожне коротке питання.

## Використані інструменти

- [заповнити: наприклад, ChatGPT, Claude, GitHub Copilot]

## Для чого використовувалися

Для кожного суттєвого випадку: хто, коли, задача, що отримано, що зроблено самостійно, як перевірено.

- Інструмент: [назва]
- Задача: [наприклад, пояснення алгоритму канонічного Гаффмана]
- Ключовий запит: [текст або суть запиту]
- Що було отримано: [пояснення, фрагмент коду, тест]
- Що зроблено студентом: [реалізовано самостійно, змінено так-то]
- Як перевірено: [unit-тести, еталонні архіви, звірка з FORMAT_SPEC]

## Що не передавалося ШІ

- приховані дані (holdout/)
- паролі і секретні ключі
- закриті матеріали викладача (FORMAT_SPEC_P2.md, еталонні архіви, якщо це заборонено)

## Відповідальність

Команда перевірила весь код, формули, тести і результати та несе відповідальність за їх правильність. Кожен учасник може пояснити будь-який фрагмент у своїй зоні.
